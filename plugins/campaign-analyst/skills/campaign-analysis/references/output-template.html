8 Methodology

This analysis follows the GOAL Platform four-layer diagnostic framework. Layer 1 parses the client's stated problem and constraints. Layer 2 builds monthly trend tables from campaign CSVs to establish baselines and classify the root cause (competitive positioning, market demand decline, budget constraint, or mixed). Layer 3 drills into source-level data — filtering to active sources with opportunities, calculating effective bids, and classifying each source's problem type (bid rate, win rate, performing, or not bidding). Layer 4 calibrates recommendations against the trailing 7-day RightPricing report, mapping each source's effective bid to its market position and cross-referencing with the source problem type. When a bid increase is indicated, both base bid and source multiplier levers are evaluated using the Base Bid vs. Multiplier Decision Framework to determine the optimal adjustment. All projections for incomplete months use the formula: (Actual Value / Days Elapsed) × Total Days in Month. Target multipliers are calculated as: (Target RPC / Base Bid) × 100%. Target base bids are calculated as: Target RPC / (Source Multiplier / 100). When a base bid change is recommended, the impact on all active sources is shown. Recommendations are prioritized by Volume Impact Potential: Opportunities × (Target Bid Rate − Current Bid Rate) × Expected Win Rate.
